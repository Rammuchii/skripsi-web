# Folder Screenshot Panduan Penggunaan

Simpan 4 screenshot tampilan website kamu di sini dengan nama file PERSIS seperti berikut:

- step-1-upload.png   -> screenshot area upload/drag-drop gambar
- step-2-berat.png    -> screenshot kolom input berat buah
- step-3-predict.png  -> screenshot tombol "Predict Now" (bisa saat progress bar jalan)
- step-4-hasil.png    -> screenshot hasil prediksi (jenis buah, confidence, harga)

Selama file belum ada di folder ini, halaman "Cara Penggunaan" otomatis
menampilkan gambar placeholder abu-abu bertuliskan nama langkahnya —
begitu file screenshot ditambahkan dengan nama yang sama, gambar asli
akan otomatis muncul menggantikan placeholder (tidak perlu ubah kode).

Rekomendasi ukuran: 800x600px atau rasio 4:3, format PNG atau JPG.
