# Folder Gambar Kelas Buah

Simpan 7 gambar contoh (satu per kelas) di sini dengan nama file PERSIS
seperti berikut:

- apple.png
- banana.png
- mango.png
- orange.png
- pineapple.png
- strawberry.png
- nonfruit.png

Rekomendasi: ambil langsung satu sampel foto dari folder dataset training
kamu per kelas (misal dataset/train/apple/<salah_satu_file>.jpg), lalu
rename dan copy ke sini sesuai nama di atas. Ini paling representatif
karena menunjukkan persis jenis gambar yang dipelajari model.

Selama file belum ada, section "Kelas Buah yang Didukung" otomatis
menampilkan placeholder abu-abu bertuliskan nama kelasnya — begitu file
ditambahkan dengan nama yang sama, gambar asli otomatis muncul
menggantikan placeholder (tidak perlu ubah kode).

Rekomendasi ukuran: persegi (1:1), minimal 300x300px, format PNG atau JPG.
